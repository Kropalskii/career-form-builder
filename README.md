
# CareerForms — сервис создания форм отклика

CareerForms — веб-приложение для самостоятельного создания, публикации и управления формами отклика на стажировки и мероприятия.

Проект разработан в рамках тестового задания на позицию младшего веб-разработчика.

## Возможности

### Административная панель

- Создание форм без написания кода.
- Добавление и удаление вопросов.
- Поддержка четырёх типов полей:
  - Короткий текст.
  - Длинный текст.
  - Электронная почта.
  - Выпадающий список.
- Настройка обязательных вопросов.
- Предпросмотр формы в реальном времени.
- Публикация формы по уникальной ссылке.
- Просмотр созданных форм.
- Просмотр полученных заявок.
- Аналитика заполнения форм.

### Форма для студентов

- Доступ к форме по уникальной ссылке.
- Заполнение обязательных и необязательных полей.
- Проверка корректности введённых данных.
- Отправка ответов на сервер.
- Уведомление об успешной отправке.

### Аналитика

Для каждой формы отображаются:

- Количество просмотров.
- Количество начатых заполнений.
- Количество отправленных заявок.
- Конверсия заполнения в процентах.

Конверсия рассчитывается по формуле:

Конверсия = (Количество заявок / Количество просмотров) × 100%.

Статистика основана на событиях, а не на уникальных пользователях. Повторные посещения могут учитываться несколько раз.

## Установка и запуск

### Требования

- Node.js версии 20 или новее.
- npm.

### Запуск

Из корневой папки проекта выполнить:

```bash
npm install
npm start
```

После запуска приложение будет доступно по адресу:

http://localhost:3000

Административная панель:

http://localhost:3000/admin

По умолчанию используется порт 3000. Его можно изменить через переменную окружения `PORT`.

## Инструкция по использованию

### Создание формы

1. Открыть административную панель.
2. Указать название и описание формы.
3. Добавить необходимые вопросы.
4. Выбрать типы полей.
5. При необходимости отметить обязательные вопросы.
6. Проверить форму в режиме предпросмотра.
7. Нажать «Опубликовать форму».

После публикации приложение создаст уникальную ссылку.

### Заполнение формы

1. Перейти по опубликованной ссылке.
2. Заполнить необходимые поля.
3. Нажать «Отправить заявку».
4. Получить подтверждение успешной отправки.

### Просмотр ответов

1. Открыть административную панель.
2. Перейти в раздел «Созданные формы».
3. Выбрать нужную форму.
4. Нажать «Посмотреть ответы».

В разделе отображаются отправленные заявки и статистика заполнения.

## API

| Метод | Маршрут | Назначение |
|-------|---------|------------|
| GET | `/api/forms` | Получение списка форм |
| POST | `/api/forms` | Создание формы |
| GET | `/api/forms/:id` | Получение конкретной формы |
| POST | `/api/forms/:id/responses` | Отправка ответов |
| GET | `/api/forms/:id/responses` | Получение ответов |
| POST | `/api/forms/:id/events` | Регистрация событий |
| GET | `/api/forms/:id/stats` | Получение статистики |

Сервер выполняет проверку структуры форм, обязательных ответов, email и допустимых вариантов выбора.

## Хранение данных

Данные сохраняются локально в JSON-файлах:

- `forms.json` — созданные формы.
- `responses.json` — ответы студентов.
- `analytics.json` — статистика заполнения.

Данные сохраняются после перезапуска приложения.

## Ограничения текущей версии

Проект реализован в формате MVP.

- Авторизация администратора отсутствует согласно требованиям задания.
- Редактирование опубликованных форм не предусмотрено.
- Аналитика учитывает события, а не уникальных пользователей.
- JSON-хранилище предназначено для локального использования и небольших нагрузок.
- Защита от массовых автоматических запросов не реализована.
- Одновременная запись большого количества запросов не оптимизирована.

## Тестирование

Проведены ручные проверки:

- Создание и публикация форм.
- Генерация уникальных ссылок.
- Отображение формы студента.
- Отправка и сохранение ответов.
- Просмотр заявок в административной панели.
- Сохранение данных после перезапуска сервера.
- Проверка обязательных полей.
- Отклонение некорректных запросов сервером.
- Проверка отображения аналитики.
